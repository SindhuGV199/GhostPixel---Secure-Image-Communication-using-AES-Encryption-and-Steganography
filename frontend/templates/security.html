Security Information & Threat Modeling

An in-depth breakdown of how GhostPixel integrates symmetric encryption, key stretching, payload hashing, and matrix steganography.

1. AES-256-GCM Authenticated Encryption

GhostPixel employs Galois/Counter Mode (GCM) with a 256-bit key. Unlike standard CBC or ECB modes, GCM provides authenticated encryption with associated data (AEAD):

  • Confidentiality: Encrypts using CTR mode counter streams.
  • Authenticity & Integrity: Computes a 128-bit authentication tag over the ciphertext using GHASH. Any bit manipulation immediately triggers an InvalidTag exception.
  • Unique Nonce: Generates a cryptographically random 96-bit (12-byte) initialization vector for every single transmission.

2. PBKDF2-HMAC-SHA256 Key Derivation

Human passphrases typically possess insufficient entropy to serve directly as a 256-bit symmetric key. GhostPixel applies rigorous key stretching:

  • 100,000 Iterations: Imposes computational cost that resists offline GPU dictionary and brute-force attacks.
  • Random 16-Byte Salt: Sourced from the operating system's CSPRNG (os.urandom), rendering precomputed Rainbow Tables completely useless.
  • Memory-Safe: Passphrases are cleared from process memory immediately after derivation.

3. Pre-Extraction SHA-256 Integrity Verification

Before submitting ciphertext to the cryptographic engine, GhostPixel verifies the SHA-256 digest of the entire packet:

  • Avalanche Effect: Flipping even a single bit in an image pixel alters on average 50% of the calculated hash bits.
  • Early Tamper Rejection: Corrupted images or active eavesdroppers modifying bits are caught before the user ever types a password.
  • Constant-Time Verification: Evaluated using hmac.compare_digest to protect against side-channel timing attacks.

4. RGB LSB Matrix Modulation

Steganographic embedding operates on 24-bit TrueColor RGB images (PNG/BMP):

  • 1 Bit per Channel: Modulates only the least significant bit (value difference of ±1 out of 255), keeping distortion far below human visual thresholds.
  • Lossless Preservation: Outputs strictly in PNG format to prevent lossy compression algorithms (e.g., JPEG DCT quantization) from destroying payload bits.
  • Capacity Safety: Validates payload dimensions against carrier dimensions prior to embedding.
